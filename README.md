# WikiRace 助手（wikiracing.org）

在 [wikiracing.org](https://wikiracing.org/) 比赛时，提示当前页面该点哪个链接。只做提示，不会替你点击。

- 面板（右下角，可拖动）列出推荐的前 8 个链接，标明 **直达 / 2 步 / 3 步** 和具体路线，例如 `→ Iran → 🎯`、`→ Fixed-wing aircraft → Malaysia → 🎯`。
- 文章里对应的链接会高亮并标上序号：金色＝目标本身，绿色＝2 步，蓝色＝3 步，紫色虚线＝按相关度推荐。
- 点面板里的条目，页面会滚动到那个链接并闪烁提示。

## 安装

先构建（需要 Node.js 18+，运行时没有外部依赖）：

```bash
node build.js
```

**方式一：Chrome / Edge 扩展（推荐）**

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择 `dist/extension` 文件夹。
4. 刷新 wikiracing.org。

**方式二：油猴脚本（Tampermonkey / Violentmonkey）**

新建脚本，把 `dist/wikirace-helper.user.js` 的全部内容粘贴进去并保存。

## 使用

进入任意一局（快速赛、自定义赛、每日挑战、好友房间都行），面板会自动出现。

| 操作 | 作用 |
|---|---|
| 点面板里的条目 | 滚动到文章里的这个链接 |
| `Alt+J` | 依次跳到第 1、2、3… 个推荐链接 |
| 面板右上角 ✕ | 把面板缩成角落里的 🧭 按钮，点 🧭 恢复 |
| `Alt+W` | 在面板和 🧭 按钮之间切换 |
| “改” | 手动输入目标（识别不到目标时用；留空回车恢复自动识别） |
| “高亮文章内链接” | 关掉后只看面板，不改文章外观 |

目标从页面上的 “Goal: …” 和网址里的 `end=` 参数识别，语言从 `language=` 参数识别（默认英文维基）。

状态栏的含义：`反链` 是已经加载的“链接到目标的条目”数量；`外圈` 只在目标比较冷门时出现，表示再往外一圈的加载进度；`请求/分` 是最近一分钟发给 Wikipedia 的请求数。

## 原理

目标在一局里不变，所以先一次性拿到目标的信息：

- 目标的所有重定向名（链接写成重定向也算直达）；
- 所有链接到目标的条目（反链，最多 3 万条，后台逐步加载）；
- 目标页面本身的链接、Wikipedia 的 `morelike:` 相关条目；
- 反链不超过 5000 条（冷门目标）时，再查最相关的 120 个反链页面各自的反链，得到“外圈”。

到达每一页时：

1. 当前页的链接直接从页面 DOM 读取（就是你能点的那些）。
2. 用上面的信号给每个链接打先验分，按先验顺序前瞻最多 10 个：用和游戏完全相同的 `action=parse` 请求拿到那一页的 HTML，套用游戏同样的清洗规则（删掉 navbox、参考文献、See also 等），得到那一页真正能点的链接。
3. 那一页能点到目标 → **2 步**；能点到某个反链页面、并且验证过那个页面确实能点到目标 → **3 步**；否则按“能点到多少个反链 / 外圈页面”排序。
4. 同一档里优先推荐文章里位置靠前的链接（少滚动），去过的页面会降分以免兜圈。

反链统计里包含 navbox 里的链接，但游戏把 navbox 删掉了，所以所有“几步可达”的结论都用清洗后的 HTML 验证过。

请求遵守 [Wikimedia 的限额](https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits)：并发 3，每分钟最多 150 次（官方对浏览器匿名用户是 200 次，给游戏自己的请求留余量），收到 429 时按 `Retry-After` 暂停。当前这一步的请求优先，后台加载反链排在最后。

## 测试

```bash
npm install          # 只为测试装 linkedom
node test/unit.js    # 离线单元测试（清洗规则、调度器、伪造的小维基上的寻路）
google-chrome --headless=new --dump-dom --virtual-time-budget=8000 "file://$PWD/test/ui-hidden.html" | grep RESULT   # 面板隐藏/恢复
node test/sim.js     # 在线模拟：每步都点排第一的链接，统计步数
node test/sim.js "Pogo stick" "Rafflesia" --think 2000
```

`sim.js` 的 `--think` 是每步点击前等待的毫秒数（模拟人读页面，默认 2000），后台的反链加载会在这段时间里继续。当前内置 10 条路线全部到达，平均 3.0 步。

## 文件

- `src/core.js`：寻路引擎，不依赖页面（浏览器和 Node 共用）
- `src/ui.js`：页面端，识别对局、读取链接、面板和高亮
- `build.js`：生成 `dist/extension`（MV3）和 `dist/wikirace-helper.user.js`

## 注意

wikiracing.org 有排位赛和排行榜。和别人比赛时用它等于作弊，建议只在单人练习、自定义赛或朋友事先同意的房间里用。
